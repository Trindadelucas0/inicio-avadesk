# Links — Lucas Rodrigues (Avadesk)
npm install
npm run dev      # http://localhost:3000
npm run build    # gera site estático em out/ (output: 'export')
npm start        # serve a pasta out/ localmente

Edite dados/links em app/page.tsx (PERFIL, LINKS, SOCIAIS).
Foto: coloque public/foto.jpg e troque o "LR" pelo <img> (comentário em app/page.tsx).
Cores: app/globals.css (variáveis --accent, --bg ...).
